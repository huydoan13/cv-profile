# cv-profile

Personal CV site for Doan Nguyen Quoc Huy, built with Next.js 16, Tailwind CSS 4, GSAP (ScrollTrigger) and Lenis.

## Run

```bash
npm install
npm run dev
```

## Where things live

- `src/data/cv.ts`: all CV content (edit this to update the site)
- `src/components/`: page sections (Hero, Manifesto, Impact, Work, Experience, Toolkit, Contact)
- `src/components/demos/`: interactive replicas of shipped features (booking rules, chat contact guard, voice notes, Shopify section editor)
- `public/Doan-Nguyen-Quoc-Huy-CV.pdf`: the downloadable CV
